Project Zero

v0.7.0 · AI Music Suite

Split any song into stems and remix it locally.

Drop in an MP3, WAV, or video file. The AI separates it into vocals, drums, bass, guitar, piano, and "other" — all running on your own machine.

  • 6-stem AI separation (htdemucs)
  • Per-stem mixer + boost
  • Mashup Lab w/ BPM sync
  • Save mix variants
  • Playlists
  • LAN sharing on Wi-Fi
Download for Windows
~360 MB · NSIS installer
Requirements
Windows 10 / 11 (64-bit). The app ships its own Python runtime and ML model; you don't need to install anything else. The Demucs model weights (~80 MB) are downloaded on first run.
